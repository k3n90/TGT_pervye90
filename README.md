# Первые 90 — демо-кабинет

Кабинет адаптации на вымышленных сотрудниках. Он показывает очередь красных сигналов, карточку новичка, чек-листы пяти треков и решение по испытанию. К Битрикс24 и к живым данным компании не подключается.

## Демо-стенд

[https://tgt.apostol-bot.ru](https://tgt.apostol-bot.ru)

## Запуск

Из этой папки:

```bash
docker compose up --build -d
```

Кабинет откроется на [http://localhost:8080](http://localhost:8080). Порт можно сменить, пример для порта 8090: `PORT=8090 docker compose up --build -d`.

Первый старт занимает пару минут: поднимается MySQL, собирается интерфейс, в базу кладутся демо-люди. Даты считаются от сегодняшнего дня, поэтому очередь красная и в понедельник, и в субботу.

Остановить:

```bash
docker compose down
```

Вместе с базой:

```bash
docker compose down -v
```

## Как смотреть

Пароль у всех ролей: `demo`. На входе достаточно нажать карточку человека.

Демо-роут:
1. **Ольга Сеницкая**, кадры — очередь «разобрать сегодня».
2. **Денис Корбут**, руководитель склада — назначить наставника Никите Бондарю. Красный сигнал про наставника после этого гаснет.
3. **Павел Остриков**, наставник склада — отметить умения Артёма Савича. Повторное «нет» на критическом пункте у Марины Крук уже сидит в очереди.
4. **Марина Ельская**, розница — жёлтые сигналы Димы Олеха. В очередь кадров они не попадают.
5. **Олег Бриль**, директор склада — сводка: доля ранних стажей среди уволившихся и отдельно доля тех, кто ещё работал на 90-й день.
6. Кнопка **Вернуть демо** собирает историю заново.

## Что внутри

- `backend` — FastAPI и правила сигналов.
- `frontend` — React.
- MySQL `pervye90`, пользователь `pervye`.
- В карточке нет паспорта, зарплаты и адреса: имя, должность, точка и рабочие отметки.
